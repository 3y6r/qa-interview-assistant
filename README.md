# QA Interview Assistant

Фронтенд и mock-сервер для проведения QA-собеседований.

## Запуск

```bash
# 1. Mock-сервер
cd mock-server-v2
npm install
npm start

# 2. Фронтенд (в другом терминале)
cd frontend-v2
npm install
npm run dev
```

Фронтенд: http://localhost:3001
Mock-сервер: http://localhost:8081
